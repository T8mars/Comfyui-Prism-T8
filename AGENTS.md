# Project rules

- Keep `roadmap.md` local only, as requested by the user. Do not stage, commit,
  push, or attach it to GitHub issues, pull requests, or releases. Do not bypass
  its Git exclusions unless the user explicitly changes this requirement.
- Preserve the pinned native-source provenance and license. Use
  `scripts/vendor_native.py` when regenerating `prism/native/`.
